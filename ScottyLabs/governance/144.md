## 1. Problem Analysis

### What Needs to Be Solved
The `template` attribute in `github_repository` is **create-only** - GitHub's API doesn't allow changing a repository's template after creation. Terraform detects this as drift and shows unnecessary "force replacement" warnings on every plan.

### Why This Matters
- Eliminates false-positive drift warnings for immutable attributes
- Prevents accidental repository recreation attempts
- Standard Terraform practice for create-only attributes

### Root Cause
Generator doesn't include `lifecycle { ignore_changes = [template] }` meta-argument to suppress drift detection on immutable attributes.

## 2. Technical Approach

Add lifecycle block to `github_repository` resource template, conditionally included only when `template` attribute is defined.

```hcl
resource "github_repository" "repo" {
  name = "example"
  
  template {
    owner      = "org"
    repository = "template-repo"
  }
  
  lifecycle {
    ignore_changes = [template]  # ponytail: create-only, immutable after creation
  }
}
```

## 3. Implementation Steps
