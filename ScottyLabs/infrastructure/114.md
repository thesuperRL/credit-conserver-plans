# Implementation Plan: Remove Port 8448 Rule in `synapse.nix`

## 1. Problem Analysis

**What needs to be solved:**
- Remove the firewall rule or network configuration that opens port 8448 in the `synapse.nix` NixOS configuration file
- Port 8448 is the default federation port for Matrix Synapse servers, used for server-to-server communication
- Removing this port suggests either:
  - Federation is being disabled
  - Federation is moving to a different port/configuration (e.g., using reverse proxy on 443)
  - The service is no longer needed

**Why it matters:**
- Reduces attack surface by closing an unnecessary port
- Simplifies firewall configuration
- Aligns with security best practices (principle of least privilege)
- May indicate migration to a more standard HTTPS-only setup via reverse proxy

## 2. Technical Approach

**Strategy:**
- Locate and remove the `networking.firewall.allowedTCPPorts` entry for port 8448
- Verify no other services depend on this port
- Check if Synapse configuration needs adjustment (e.g., disabling federation, or confirming reverse proxy handles it)
- Ensure the change doesn't break existing functionality

**Key decisions:**
- Simple deletion vs. commenting out (choose deletion for clean config)
- Whether to verify Synapse's `homeserver.yaml` configuration alongside the NixOS config
- Whether to check for any service dependencies on this port
